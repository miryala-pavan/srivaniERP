# Project Instructions — Srivani Stores ERP

These rules apply across every session working in this repository, regardless of which machine or window it's opened from.

## UI standard: every list needs sortable headers and filters

Any screen that shows a list or table — search results, product lists, GRN, suppliers, customers, PLU management, Unit Management, reports, or anything similar — must have:
- **Column-header sorting** (click a header to sort by that column, both directions)
- **Filters** appropriate to that data (status, category, date range, etc. — whatever fields make sense for that list)

This is a standing requirement for every list in the app, not just the ones it was originally requested for. Apply it whenever building a new list view or touching an existing one that's missing it.
